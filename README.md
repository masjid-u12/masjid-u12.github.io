# Masjid U12, Cahaya Alam

Laman landing page statik untuk cadangan pembinaan Masjid U12, Cahaya Alam, Seksyen U12, Shah Alam.

- `index.html`: satu halaman, CSS dan JavaScript di dalamnya
- `img/`: lukisan arkitek dan logo
- `.nojekyll`: supaya GitHub Pages menghidangkan fail apa adanya

Kandungan diambil daripada Kertas Kerja Cadangan Pembinaan Masjid U12, draf V1, Ogos 2026.
Angka kos ada dalam tatasusunan `KOS` di bahagian skrip `index.html`.
